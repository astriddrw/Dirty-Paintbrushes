# Redesign options (exploration only, not wired into the app)

Design-canvas mockups for two optional redesign directions of the homepage and feed.
Live, interactive canvas: https://claude.ai/artifact/PNi2a3CDjeWqeeB1TS5QuU (private to the owner).

- `Main.dc.html`, `A-Feed.dc.html`: Option A "The Broadsheet" (current palette, newspaper front page, wire ticker, highlighter and margin notes, stamps).
- `B-Home.dc.html`, `B-Feed.dc.html`: Option B "The Investigation Desk" (dark newsroom palette, red-string evidence board, dossier panel, index-card feed).

All headlines, sources and dates in these files are placeholder samples, not real cases.
